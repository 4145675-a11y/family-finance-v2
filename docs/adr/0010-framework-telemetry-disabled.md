# ADR-0010: טלמטריית Next מושבתת ב־CI; ההשבתה המקומית מתועדת ואינה נכפית

- **Status**: **Superseded by [ADR-0011](0011-next-launcher-telemetry.md)**
- **Date**: 2026-08-16
- **Milestone**: 1
- **Requirement IDs**: —

> **הערת החלפה**: ההחלטה על CI נשארת בתוקף. מה שהוחלף הוא סעיף 2 — ההסתמכות על כך שמפתח יזכור לייצא משתנה סביבה מקומית. ADR-0011 מחליף אותה ב־launcher שאוכף את החסימה בכל פלטפורמה, ובבדיקה שמונעת רגרסיה.

## הקשר

ה־build הראשון של Next הדפיס:

> Attention: Next.js now collects completely anonymous telemetry regarding usage.

`07-SECURITY-PRIVACY.md` דורש שליטה במה שיוצא מהמערכת. גם אם המידע אנונימי, פרויקט שמנהל נתונים פיננסיים של משפחה אינו שולח מדדי שימוש כברירת מחדל.

בעיה נוספת, ספציפית לפרויקט הזה: הפקודה הרשמית `next telemetry disable` כותבת קובץ הגדרות **ברמת המשתמש**, מחוץ לשורש הפרויקט. גבול הבטיחות ב־`CLAUDE.md` אוסר כתיבה מחוץ לפרויקט, ולכן אסור להריץ אותה.

## החלטה

1. **ב־CI**: `NEXT_TELEMETRY_DISABLED: '1'` מוגדר ברמת ה־workflow ב־`.github/workflows/ci.yml`. כל build אוטומטי רץ בלי טלמטריה, ללא תלות בזיכרון של אף אחד.
2. **מקומית**: מתועד ב־`docs/COMMANDS.md` שיש לייצא `NEXT_TELEMETRY_DISABLED=1`. **לא** נוצר קובץ `.env` מחויב לשם כך: `.gitignore` חוסם `.env*` בכוונה, וחריגה נקודתית עבור משתנה נוחות פותחת פתח לקובץ סביבה מחויב שבהמשך יקבל סוד.
3. `next telemetry disable` **לא הורצה ולא תורץ** — היא כותבת מחוץ לשורש הפרויקט.

## הודאה מלאה

ה־build הראשון של Milestone 1 רץ **לפני** שההחלטה הזו התקבלה, עם טלמטריה פעילה כברירת מחדל. ייתכן שהוא רשם רישום ראשוני בתיקיית הגדרות ברמת המשתמש. לא ניגשתי לאותו נתיב ולא ניקיתי אותו — גבול הבטיחות אוסר עליי לגעת בו, וניקוי היה מחייב בדיוק את החריגה שהכלל מונע.

מי שרוצה להסיר את הרישום צריך להריץ בעצמו, מחוץ להקשר הזה: `npx next telemetry disable`.

## חלופות שנשקלו

| חלופה | מדוע נדחתה |
|---|---|
| `next telemetry disable` | כותבת מחוץ לשורש הפרויקט — אסור |
| `.env` מחויב עם המשתנה | חריגה ב־`.gitignore` שמכשירה קובץ סביבה מחויב; סיכון עתידי לסוד |
| חבילת `cross-env` בסקריפט | תלות שלמה עבור משתנה סביבה יחיד |
| env ב־CI + תיעוד מקומי (נבחר) | מכסה את הנתיב האוטומטי במלואו, בלי תלות ובלי חריגה |

## השלכות

- חיוביות: אף build אוטומטי אינו שולח טלמטריה; ההחלטה גלויה בקובץ ה־workflow.
- שליליות: build מקומי של מפתח שלא ייצא את המשתנה עדיין ישלח. זו הבחירה שלו, על מכונה שלו.
- לאימות: `.github/workflows/ci.yml` מכיל את המשתנה ברמת ה־job.

## תנאי ביטול

אם Next יאפשר השבתה דרך `next.config.ts` — לעבור לשם, כי זה מכסה גם build מקומי בלי משתנה סביבה.
