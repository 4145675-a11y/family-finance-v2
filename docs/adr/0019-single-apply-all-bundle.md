# ADR-0019: חבילת החלה אחת לכל המיגרציות

- **Status**: Accepted
- **Date**: 2026-08-23
- **Milestone**: 3
- **Requirement IDs**: `SEC-RLS-001`
- **Supersedes**: את שמות הקבצים והפקודות שנקבעו במסגרת `ADR-0015`

## הקשר

`ADR-0015` הוסיף זרימת החלה ידנית בשתי פקודות, אחרי שהדבקה קובץ־קובץ נכשלה פעמיים. הקבצים נקראו `m2-apply-all.sql` ו־`m2-diagnostic.sql`, ובונה החבילה קרא **את כל** המיגרציות בתיקייה.

Milestone 3 הוסיף שלוש מיגרציות. הבונה צירף אותן מיד — לתוך קובץ ששמו טוען שהוא Milestone 2. הבחירה הייתה בין קובץ ששמו משקר, לבין פיצול החבילה לפי milestone.

פיצול לפי milestone נדחה: הוא מחייב את הבונה לדעת איזו מיגרציה שייכת לאיזה שלב — מיפוי שאין לו מקור אמת מלבד תחילית התאריך בשם הקובץ, והוא היה נשבר בכל פעם שמיגרציה מתווספת לשלב קודם.

מכריע נוסף: **שום מיגרציה לא הוחלה עדיין**. אין מסד עם Milestone 2 עליו שצריך תוספת בלבד. ההחלה הראשונה, כשתתרחש, היא של הסכמה כולה.

## החלטה

חבילה אחת, `supabase/manual/apply-all.sql`, המכילה כל מיגרציה במאגר לפי סדר שם הקובץ, עטופה ב־`begin; … commit;` יחיד. האבחון נקרא `diagnostic.sql` ומכסה את כל הטבלאות, ה־types, הפונקציות והטריגרים.

הפקודות:

| קודם | עכשיו |
|---|---|
| `npm run db:build:m2` | `npm run db:build` |
| `npm run db:check:m2` | `npm run db:check` |
| `npm run db:copy:m2` | `npm run db:copy:schema` |
| `npm run db:copy:diagnostic` | ללא שינוי |

כל המיגרציות ניתנות להרצה חוזרת לפי `ADR-0015`, ולכן הרצת החבילה על סכמה שהוחלה חלקית מגיעה לאותה תוצאה כמו הרצה על מסד נקי.

## חלופות שנשקלו

- **חבילה לכל milestone** — נדחה: דורש מיפוי milestone→מיגרציה שאין לו מקור אמת, ומכפיל את מספר ההדבקות הידניות שבהן טעות אנוש כבר קרתה פעמיים.
- **להשאיר את השם `m2-apply-all.sql`** — נדחה: קובץ שמכיל שמונה מיגרציות משלושה milestones ושמו טוען אחרת הוא בדיוק סוג התיעוד שגורם לטעות בהחלה.
- **תוספת בלבד מעל M2** — נדחה: מניח שמיגרציות 1–5 הוחלו, וזו הנחה שלא אומתה.

## השלכות

- `tools/manual-sql.test.mjs` ממשיך לשחזר את המקורות מתוך החבילה ולאמת שדבר לא נוסף, נגרע או שונה סדר — כעת על שמונה מיגרציות.
- `npm run db:check` הוא חלק מ־`npm run verify`, כך שחבילה שסטתה מהמקורות מפילה את השער.
- ההוראות ב־`supabase/README.md` וב־`docs/checkpoints/milestone-2.md` עודכנו לשמות החדשים.
